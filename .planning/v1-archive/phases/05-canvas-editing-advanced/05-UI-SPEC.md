All Phase 04 color tokens are inherited unchanged. Phase 05 adds terrain and overlay color values only.

| Role | Radix token / Hex | Usage |
|------|-------------------|-------|
| Dominant (60%) | Radix `--color-background` (light: #ffffff / near-white) | Page background, canvas container — UNCHANGED |
| Secondary (30%) | Radix `--color-panel-solid` (light: #f9f9f9) | Cards, panels, toolbar — UNCHANGED |
| Accent (10%) | Radix `iris` | Active "Pintar Terreno" button (solid variant), active terrain type chip — UNCHANGED reserved set from Phase 04 |

| Success | Radix `green` | Save status "Salvo ✓" — UNCHANGED |

### Terrain Color Palette (Konva canvas fills — cannot use CSS variables)

Applied to territory polygon fill when 'terrain' layer toggle is ON. Chosen to be visually distinct from each other AND from the existing kingdom color palette (which is generated from `condado_colors.json` heuristic colors in the blue/green/amber range).

| Terrain Type | Hex | Rationale |
|---|---|---|
| Montanha (Mountain) ⛰️ | `#9e9e9e` | Cool mid-gray — rocky, neutral, distinct from any kingdom hue |
| Floresta (Forest) 🌲 | `#2d6a2d` | Deep forest green — dark enough to not conflict with lighter kingdom greens |
| Planície (Plains) 🌾 | `#c8b870` | Warm yellow-tan — historically accurate, avoids overlap with amber kingdom colors |
| Rio (River) 🌊 | `#5b8db8` | Muted steel blue — distinct from any condado fill; readable without being harsh |
| Árido (Arid) 🏜️ | `#c27b3a` | Warm burnt orange-tan — desert look, distinct from forest and plains |

Territory fill opacity in terrain mode: `opacity=1` (solid fill replaces kingdom color entirely when terrain layer is ON).

Territory fill when terrain layer is ON but no terrain is assigned: `#d4d4d4` (Radix gray-4 approximate — neutral "unpainted" state).

### Overlay Layer (Konva Image node)

Overlay Konva Image: no fill, no stroke. Opacity controlled by `overlayOpacity` from `useUIStore` (0.0–1.0). Initial value: 0.5. The image is rendered at the map's native resolution and positioned at `x=0 y=0` of the map coordinate space (same origin as BackgroundLayer). Scaling matches the Stage transform automatically.

### Brush Cursor (canvas interaction affordance)

While the paint tool is active and the mouse is over the Stage, a circle cursor preview is rendered as a non-interactive Konva Circle:
- `fill="rgba(255,255,255,0.15)"` (very faint white)
- `stroke` = the current terrain's hex color (see palette above)
- `strokeWidth=1.5`
- `radius` = current `brushRadius` value in canvas pixels
- `listening={false}`

This cursor circle follows `onMouseMove` and disappears when the mouse leaves the Stage (`onMouseLeave`).

### Terrain Type Selector — UI Pattern

Rendered as a compact Radix `SegmentedControl` or as a row of icon+label `Button` elements (variant="soft" when inactive, variant="solid" with terrain-specific accent when active). Each item shows the emoji + Portuguese name:

```
[⛰️ Montanha] [🌲 Floresta] [🌾 Planície] [🌊 Rio] [🏜️ Árido]
```

Use Radix `SegmentedControl.Root` + `SegmentedControl.Item` (size="1" to keep toolbar compact). The active item renders with the iris accent (Radix default for SegmentedControl active state). Do NOT use custom terrain colors for the selected state — iris accent is the established active indicator (Phase 04 D-09).

### Reference Overlay Panel — UI Pattern

Radix `Card` (variant="surface"), positioned absolute bottom-left of the canvas, above FitToViewButton: `bottom: 52px, left: 12px, zIndex: 10, width: 200px`.

Contains:
1. `<Text size="2" weight="bold">Sobreposição</Text>` heading
2. File input trigger: Radix `Button` size="1" variant="soft" label "Carregar imagem…" — clicks a hidden `<input type="file" accept="image/*">`. Once loaded, file name shown as `<Text size="1" color="gray">`.
3. Opacity slider: Radix `Slider` component, `min=0 max=1 step=0.05 defaultValue=[0.5]`. Label above: `<Text size="1">Opacidade</Text>`. Current value shown inline: `<Text size="1" color="gray">{Math.round(opacity*100)}%</Text>`.
4. Clear button: Radix `Button` size="1" variant="ghost" color="gray" label "Remover" — sets `overlayImageUrl: null`. Only visible when an image is loaded.

The panel is always visible when edit mode is ON (not conditional on a tool selection — reference overlay is independent of the paint tool).

## Interaction Contract

All Phase 04 interactions (capital drag, vertex edit, rubber-band, merge, split, undo/redo, save status) carry forward unchanged. Phase 05 adds two independent tools.

### Terrain Paint Brush (D-01, D-02, D-03, EDIT-05)

**Activation:**
- User clicks "Pintar Terreno" button in EditToolbar (only available in edit mode).
- ToolMode enum gains `'paint'` value. `setActiveTool('paint')` is called. Button renders `variant="solid"` (iris).
- Stage cursor: `cursor: crosshair` on the wrapping div when paint tool is active.

**Brush radius unit:** Canvas pixels (Konva stage coordinate system). Geographic km would warp non-linearly as the user zooms in/out. Pixels provide a consistent visual radius at any zoom level.

**Brush radius control:**
- Radix `Slider` in EditToolbar inline with other paint controls.
- Range: `min=10 max=80 step=5 defaultValue=[30]`.
- Stored in `useEditorStore` as `brushRadius: number`.
- Label: `<Text size="1">Raio: {brushRadius}px</Text>` immediately left of the slider.

**Paint interaction:**
1. `onMouseDown` (Stage, in paint mode): call `temporal.pause()` to begin undo transaction.
2. `onMouseMove` (Stage, while mousedown held): compute cursor position in canvas coordinates, find all condado centroids within `brushRadius` pixels, add to stroke accumulator set. Optimistically update `terrain_types` in `useProjectStore` for those ids immediately (no API call during drag — only on mouseup).
3. `onMouseUp` (Stage): flush accumulated territory_ids → `POST /api/edit/paint-terrain { territory_ids, terrain_type }`. On success: call `temporal.resume()`, push undo label. On error: revert optimistic updates, call `temporal.resume()`, show error toast.
4. Brush cursor circle (non-interactive Konva Circle) follows mouse position throughout.

**Optimistic update / rollback pattern:** Mirror exactly the `handleCapitalDragEnd` rollback pattern from CanvasViewer.tsx. Capture pre-stroke `terrain_types` snapshot before `pause()`. On error, restore snapshot before calling `resume()`.

**Land mask guard:** Backend silently excludes ocean territory_ids from `painted_ids` response. Frontend applies `terrain_types` only for IDs in `painted_ids`. IDs in `skipped_ids` retain their prior terrain assignment. No error toast for skipped ocean territories.

**Empty terrain state (terrain layer ON, no territory painted):** All territories render with `#d4d4d4` fill (neutral unpainted gray). Emoji badges are not rendered for territories without a `terrain_types` entry. The layer is visually quiet until the user begins painting.

**Undo label format:** `"Pintar {terrainLabel} — {N} condado(s)"` where `terrainLabel` is the Portuguese name (e.g. `"Montanha"`, `"Floresta"`). Format: `"Pintar Montanha — 3 condados"` (as specified in CONTEXT.md D-03).

**Keyboard shortcut:** `P` activates paint tool when edit mode is ON (consistent with single-key tool shortcuts from Phase 04: E=edit, V=vertex, S=split).

**Exit paint tool:** Esc or clicking another tool button. On exit: brush cursor circle removed, Stage cursor resets to default.

### Terrain Layer Toggle (D-02)

- `LayerName` extended to include `'terrain'`.
- Default visibility: OFF.
- Label in LayerTogglePanel: `"Terreno"` (no tooltip needed — behavior is immediate and visible).
- When ON: territory fills switch to terrain color from palette. Kingdom colors are hidden.
- When OFF: territory fills use kingdom colors (current behavior restored). This is a rendering mode switch, not a data change — no backend call, no undo step.
- Emoji badges (`TerrainBadgesLayer`) are always rendered regardless of the terrain toggle, additive above territory polygons.

### Terrain Emoji Badges (D-02)

- Rendered by `TerrainBadgesLayer` as Konva Text nodes at each condado centroid.
- Only rendered for territories that have a `terrain_types` entry.
- Emoji per type: mountain=⛰️, forest=🌲, plains=🌾, river=🌊, arid=🏜️.
- Konva Text props: `fontSize=14`, `listening={false}`, `align="center"`, `verticalAlign="middle"`, `offsetX=7`, `offsetY=7` (centers the glyph over the centroid point).
- No font family required for emoji (system emoji font renders correctly on all platforms via native Konva Canvas text rendering).
- `clearCache()` is called on the TerrainBadgesLayer after any geometry change to prevent hit canvas desync (per CONTEXT.md critical constraint).

### Reference Overlay (D-04, EDIT-06)

- File picker: hidden `<input type="file" accept="image/*">`. Trigger: Radix Button "Carregar imagem…" in ReferenceOverlayPanel.
- On file select: `URL.createObjectURL(file)` → set `overlayImageUrl` in `useUIStore`.
- Konva Image node in `TerrainOverlayLayer`:
  - Z-order: above `BackgroundLayer`, below `TerritoryLayer` (between the two in the Stage child list).
  - Position: `x=0 y=0`, `width=projection.mapW`, `height=projection.mapH` — covers the full map area.
  - `opacity={overlayOpacity}` from `useUIStore`.
  - `listening={false}` — overlay is purely decorative, does not intercept mouse events.
- `clearCache()` called on the overlay Konva Image after any geometry change (per CONTEXT.md D-04 critical constraint).
- Opacity slider drives `useUIStore.setOverlayOpacity(value)` → Konva Image re-renders reactively.
- File validation: `accept="image/*"` on the file input provides first-line guard. If browser passes a non-image MIME type through, catch the Konva Image `onError` and fire a toast: `"Arquivo inválido. Carregue uma imagem (PNG, JPEG, WebP)."` (red toast, 6000ms).
- Clear: `overlayImageUrl` set to null. `URL.revokeObjectURL()` called on the old URL to release memory.
- Ephemeral: `overlayImageUrl` is NOT persisted to SQLite and NOT included in undo history. Lost on page reload — intentional.

### Konva Layer Z-Order — Phase 05 (complete stack)

```
BackgroundLayer          (terrain PNG)
TerrainOverlayLayer      (reference image, opacity-controlled) ← NEW
TerritoryLayer           (condado polygons — kingdom OR terrain colors)
BaronyLayer              (barony polygons at 85% opacity)
TerrainBadgesLayer       (emoji badges at centroids)           ← NEW
DecorationsLayer         (capitals + territory labels)
InteractionLayer         (gold selection outline)
VertexHandlesLayer       (conditional: vertex edit mode only)
RubberBandLayer          (conditional: rubber-band drag rect)
SplitPreviewLayer        (conditional: split tool active)
ValidationBadgesLayer    (error/warning dots at centroids)
```
