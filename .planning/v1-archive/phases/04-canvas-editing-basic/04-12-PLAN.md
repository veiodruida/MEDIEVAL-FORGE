<objective>
Add shift-click multi-select to territory click handling so a user can Ctrl/Shift-click multiple territories to build up a selection for Fundir (merge). This closes the secondary gap in UAT T3: rubber-band drag was the only multi-select affordance shipped in Phase 4, but SC3 promised shift-click too. User feedback: "tentei usar shift nao funcionou".

Scope is deliberately narrow — reuse the existing `rubberBandSelectionIds` field on useEditorStore (already consumed by SelectionFloatingToolbar at length ≥ 2) so merge UI lights up automatically without any toolbar changes.

Performance constraint (checker MINOR 6): the click handler is consumed by up to 800 TerritoryPolygon children wrapped in React.memo. Closing over `rubberBandSelectionIds` via a selector would cause handleClick to change identity on EVERY shift-click → full child re-render storm → contradicts the <500ms target. Handler must be reference-stable.

Purpose: Deliver the missing SC3 multi-select affordance with minimal surface area — one event-handler branch + one store field reuse, AND keep the handler stable to protect re-render performance.

Output: Shift-click in edit mode toggles condado id membership in rubberBandSelectionIds; plain click is unchanged; rubber-band drag is unchanged; handleClick identity is stable across clicks.
</objective>

    New handleClick — DO NOT use store selectors for rubberBandSelectionIds /

    ```tsx
    // Stable across shift-click mutations: handleClick has NO state deps.
    // Reading via getState() inside the body sees fresh values on each call but
    // keeps the callback reference === so React.memo on TerritoryPolygon does
    // not invalidate. Essential at 800 territories (checker MINOR 6, <500ms target).
    const handleClick = useCallback((id: string, shift: boolean) => {
      const editor = useEditorStore.getState()
      const ui = useUIStore.getState()

      // Shift-click only engages multi-select in edit mode (gap-closure 04-12).
      // Outside edit mode, fall through to plain single-select.
      if (shift && editor.editMode) {
        // Toggle membership in the existing rubber-band selection set.
        // SelectionFloatingToolbar renders Fundir when length >= 2, so this
        // automatically lights up the merge UI without further wiring.
        const current = editor.rubberBandSelectionIds
        const next = current.includes(id)
          ? current.filter((x) => x !== id)
          : [...current, id]
        editor.setRubberBandSelectionIds(next)
        return
      }

      // Plain click: clear any multi-select from a prior shift-click/rubber-band
      // and set a single selection. Matches rubber-band UX (new selection clears
      // the old one).
      if (editor.rubberBandSelectionIds.length > 0) {
        editor.clearRubberBandSelection()
      }
      ui.select(id)
    }, [])  // ← intentionally empty: all reads are via getState() above
    ```
