# Phase 02.1 Plan 03: HydroSHEDS Basin Ingestion Summary

**One-liner:** geopandas-backed HydroSHEDS lv6 basin clip via GDAL bbox spatial filter, vendored EU shapefile, SSE runner writing raw/basins.geojson with id/next_down/sub_area schema.

## What Was Built

Implemented GEO-05: HydroSHEDS lv6 basin polygon ingestion for project bbox.

**hydrosheds.py** — `fetch_basins(bbox, queue, *, stop_event)`:
- Constructs shapefile path exclusively via `importlib.resources.files("medieval_forge.data.hydrosheds") / "hybas_eu_lev06_v1c.shp"` (T-03-01 path-traversal mitigation)
- Calls `geopandas.read_file(path, bbox=bbox)` wrapped in `asyncio.to_thread` (T-03-03: GDAL spatial index filters at read time; event loop stays free)
- Renames `HYBAS_ID → id`, `NEXT_DOWN → next_down`, `SUB_AREA → sub_area` (D-23 schema)
- Returns `{"type":"FeatureCollection","features":[]}` on empty bbox without error
- Emits Portuguese SSE progress logs ("bacias") to caller queue

**runner.py** — `run_terrain_hydrosheds(project_id, queue, *, stop_event, db_session_factory)`:
- Same shape as `run_terrain_overpass` (db_session_factory injection for test isolation)
- Early stop_event check before `_resolve_bbox`
- Writes output to `raw/basins.geojson` via `_write_geojson_atomic`

**api/terrain.py** — `/hydrosheds` endpoint:
- Replaces 501 stub with live SSE streaming endpoint
- UUID-validates project_id (T-PATH)
- Only `/dem` and `/ridges` remain as 501 stubs (Plans 04, 05)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] stub_geopandas infinite recursion fix**
- **Found during:** Task 0b implementation
- **Issue:** Plan spec's stub called `gpd.read_file(path)` inside `monkeypatch.setattr(gpd, "read_file", ...)` — infinite recursion after patching
- **Fix:** Replaced inner `gpd.read_file` call with `gpd.GeoDataFrame.from_features(json.load(...))` — builds GeoDataFrame from fixture without re-entering the patched function
- **Files modified:** `backend/tests/test_terrain_basins.py`

**2. [Rule 3 - Blocking] Relative fixture path → absolute path**
- **Found during:** Task 0b implementation
- **Issue:** Plan spec used `Path("backend/tests/fixtures/...")` — breaks when pytest is run from a directory other than repo root
- **Fix:** Changed to `FIXTURES_DIR = Path(__file__).parent / "fixtures"` (mirrors conftest.py convention)
- **Files modified:** `backend/tests/test_terrain_basins.py`

### Expected Deviations (Task 0a delivery)

**3. EU shapefile filename: `hybas_eu_lev06_v1c` instead of `hybas_lev06_v1c`**
- **Context:** Plan specified the global HydroSHEDS file (`hybas_lev06_v1c`). The user downloaded the Europe-only subset (`hybas_eu_lev06_v1c`).
- **Impact:** Projects with bboxes outside Europe will receive an empty `basins.geojson` FeatureCollection silently. Phase 2.2 territory clustering will have no watershed constraint for non-European projects.
- **Acceptable for:** Current Iberia-focused use case (Reconquista 868 AD).
- **Future:** If global coverage is needed, download `hybas_lev06_v1c` global file and update `_shapefile_path()` in `hydrosheds.py`.
- **Files modified:** `hydrosheds.py` (filename reference), `runner.py` (no change needed — delegates to hydrosheds.py)
