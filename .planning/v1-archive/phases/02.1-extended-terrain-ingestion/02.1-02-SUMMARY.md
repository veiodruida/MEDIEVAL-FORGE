# Phase 02.1 Plan 02: Overpass Terrain Quartet Summary

**One-liner:** 4 Overpass QL fetchers (rivers/topography/coastline/parishes) with SSE orchestrator, MultiLineString wrap contract, and graceful-empty parishes handling.

## What Was Built

### Task 0 — RED tests (`test_terrain_overpass.py`)

10 failing tests covering all 4 datasets and the runner SSE:
- Rivers: feature count, property schema `{id, waterway, name}`, LineString geometry
- Topography: peak with float elevation (string→float parse), Point geometry
- Coastline: single `MultiLineString` feature even when 1 way (Pitfall 2 / D-03)
- Parishes: empty FeatureCollection + `"Sem parishes"` SSE log (D-04 graceful empty)
- Runner: writes 4 files, no `.tmp` files remaining, stop_event cancellation

### Task 1 — GREEN implementation

**`overpass_terrain.py`** — 4 async fetchers:
- `fetch_rivers`: way elements → `{id, waterway, name}` LineString features
- `fetch_topography`: node/way elements → `{id, natural, name, ele}` Point/LineString features; `ele` parsed as float from OSM string
- `fetch_coastline`: ways → `linemerge` → always `MultiLineString` (D-03 contract)
- `fetch_parishes`: relation elements → `_relation_to_geojson_feature` reuse + parish property reshape; empty FC + SSE log when 0 results (D-04)
- T-02-01: only static frame messages in SSE (no raw OSM names/tags leaked)

**`runner.py`** — SSE orchestrator:
- `register_stop_event` / `get_stop_event` / `clear_stop_event` — (project_id, step) scoped registry (T-01-04 / T-02-02)
- `_resolve_bbox` — reads `Project.bbox_*` from DB via injected session factory
- `_maybe_split_bbox` — D-21: recursively splits >30° bboxes on longest axis
- `run_terrain_overpass` — iterates 4 fetchers, atomic-writes each file, emits SSE progress; `exc.__class__.__name__` in SSE (T-02-05)

**`api/terrain.py`** (stubs replaced):
- `POST /overpass` — UUID-validated, spawns `run_terrain_overpass` task, returns SSE StreamingResponse
- `POST /stop` — UUID-validated, step whitelisted, looks up + sets stop_event (T-02-02)
- `/hydrosheds`, `/dem`, `/ridges` remain 501 for Plans 03-05

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed `line_merge` import name**
- **Found during:** Task 1 execution (ImportError at module import)
- **Issue:** Plan spec used `from shapely.ops import line_merge` but Shapely 2.x exports `linemerge` (no underscore)
- **Fix:** `from shapely.ops import linemerge as line_merge`
- **Files modified:** `overpass_terrain.py`
- **Commit:** 7cd9014

**2. [Rule 3 - Blocking] Added `db_session_factory` parameter to `run_terrain_overpass`**
- **Found during:** Task 0 test design (advisor consultation)
- **Issue:** Plan spec had runner using production `AsyncSessionLocal` directly. Tests with in-memory DB cannot reach it. `tmp_raw_dir` provides filesystem but no DB row — `_resolve_bbox` would always return None.
- **Fix:** Added `db_session_factory: async_sessionmaker | None = None` parameter (mirrors `ingest_runner.run_ingest`). Tests inject `factory` from `terrain_env` fixture.
- **Files modified:** `runner.py`, `test_terrain_overpass.py`
- **Commit:** 7cd9014

**3. [Rule 3 - Blocking] Added early stop_event check before `_resolve_bbox`**
- **Found during:** Task 0 test design (advisor consultation)
- **Issue:** Plan spec checked stop_event only inside the per-step loop. `test_run_terrain_overpass_honors_stop_event` would see `"ERROR: project bbox não definido"` (from the DB lookup) instead of `"Cancelado"`.
- **Fix:** Added `if stop_event.is_set(): raise asyncio.CancelledError(...)` as first statement in `try:` block.
- **Files modified:** `runner.py`
- **Commit:** 7cd9014

**4. [Rule 3 - Blocking] Added `terrain_env` composed fixture**
- **Found during:** Task 0 test design (advisor consultation)
- **Issue:** Existing `tmp_raw_dir` fixture provides only filesystem; runner tests also need a Project row with bbox columns. Plan did not specify how to compose these.
- **Fix:** `terrain_env` async fixture creates in-memory SQLite DB, inserts a Project with bbox, monkeypatches PROJECTS_ROOT, and yields `(project_id, raw_dir, session_factory)`.
- **Files modified:** `test_terrain_overpass.py`
- **Commit:** 34f4ca5
