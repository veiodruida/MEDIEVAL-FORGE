## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `resp.raise_for_status()` fails when response has no request object**
- **Found during:** Task 1 GREEN run — `test_fetch_dem_concurrency_is_capped_at_four` mock returns `httpx.Response(200, content=...)` without a request; `raise_for_status()` raises `RuntimeError: Cannot call raise_for_status as the request instance has not been set`
- **Fix:** Replaced `resp.raise_for_status()` with explicit `if resp.status_code >= 400: raise httpx.HTTPStatusError(...)` — avoids the request dependency
- **Files modified:** `backend/medieval_forge/services/ingest_terrain/dem.py`
- **Commit:** 2d605bd

**2. [Rule 1 - Bug] DEM cache isolation missing in integration tests**
- **Found during:** Full regression run — `test_fetch_dem_skips_404_ocean_tiles` passed in isolation but failed in full suite because a previously-run test had written real tiles to `~/.medieval-forge/dem_cache/`; those tiles were returned as "cache hit" bypassing the mock
- **Fix:** Added `monkeypatch.setattr(dem_mod, "DEM_CACHE_DIR", tmp_path / "dem_cache")` to all three async test functions
- **Files modified:** `backend/tests/test_terrain_dem.py`
- **Commit:** 2d605bd
