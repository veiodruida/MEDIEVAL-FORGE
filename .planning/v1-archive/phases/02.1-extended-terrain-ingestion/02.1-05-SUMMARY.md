# Phase 02.1 Plan 05: Ridge Derivation Summary

**One-liner:** Slope + negative-laplacian + skeletonize pipeline derives ridge polygons and centerlines from DEM, with deterministic SHA1-12 IDs and OSM/basin cross-reference.

## What Was Built

### ridges.py — `derive_ridges()` function

Full pipeline per D-14:
1. Read DEM via rasterio; mask nodata
2. Gaussian smooth (sigma=1.5) to denoise crests
3. Slope in degrees via `np.gradient + arctan(hypot)`
4. Unnormalized negative laplacian via `scipy.ndimage.laplace`
5. Threshold mask: `(slope > s_min) AND (lap > c_min) AND valid`
6. Skeletonize with `skimage.morphology.skeletonize(mask.astype(bool))` — Pitfall 6
7. Polygonize mask via `rasterio.features.shapes` → filter by area threshold in deg²
8. Centerline extraction from skeleton pixels inside each polygon
9. OSM peak cross-ref for `peak_count` + `name` (optional, graceful degradation)
10. HydroSHEDS basin cross-ref for `basin_ids[]` (optional, graceful degradation)
11. Deterministic IDs: `sha1(f"{cx:.3f}|{cy:.3f}|{int(round(elev_max))}".encode())[:12]` — Pitfall 7

### Calibrated THRESHOLDS (Wave 0 probe result)

```
Synthetic DEM: z.std ≈ 367, lap_raw range -7.9..58.1, slope range 0..90°
slope>30 AND lap_raw>0.002 → 840 mask cells, 2 skeleton components, 2 polygons
Polygon areas ≈ 4.2e-2 deg² >> min threshold 4.06e-4 (5e6m²/111000²)
```

THRESHOLDS dict (matches RESEARCH.md §4 starting values — validated correct):
- low: slope>25°, curvature>0.001, min_area=1e6 m²
- med: slope>30°, curvature>0.002, min_area=5e6 m²
- high: slope>35°, curvature>0.003, min_area=1e7 m²

### runner.py — `run_terrain_ridges()`

- Checks `raw/dem.tif` exists (returns SSE error if not)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Removed laplacian normalization from plan draft**
- **Found during:** Task 0 calibration probe
- **Issue:** Plan draft divided lap by `z_smooth.std()` (≈367 for synthetic DEM), making `lap_norm` ≈ 100× smaller than the `curvature_min` thresholds (0.001–0.003). At `med`, the normalized curvature would never exceed 0.002, yielding 0 ridge polygons — the test would fail.
- **Fix:** Use unnormalized laplacian matching RESEARCH.md §4 (`lap = -ndimage.laplace(z_smooth)`). Calibration confirmed 2 components at med sensitivity with unnormalized values.
- **Files modified:** ridges.py (implemented without normalization)
- **Commit:** b1b0fdd

**2. [Rule 1 - Bug] Fixed DeprecationWarning in 412 test**
- **Found during:** Task 1 test run
- **Issue:** `asyncio.get_event_loop().run_until_complete()` raises DeprecationWarning in Python 3.10+ ("There is no current event loop").
- **Fix:** Changed test to `@pytest.mark.asyncio async def` (compatible with `asyncio: mode=Mode.AUTO` already configured in pyproject.toml).
- **Files modified:** test_terrain_ridges.py
- **Commit:** b1b0fdd (same)
