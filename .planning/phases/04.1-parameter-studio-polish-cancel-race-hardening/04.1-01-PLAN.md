<objective>
Close WR-02 (D-05): evict `_RUN_QUEUES[project_id]` and `_RUN_TASKS[project_id]` in the `finally` blocks of `_render_producer` and `_generate_producer` so that a late-arriving `GET /render/stream` (or `/generate/stream`) call returns 404 instead of hanging forever on a drained queue.

Purpose: Phase 04 left these two dicts populated after a run completed. The stream endpoints check `queue = _RUN_QUEUES.get(project_id)` and only 404 when the key is absent. After a run, the key was still present but the queue was drained — a refresh-mid-finished-run produced an indefinite hang. This is a backend-only fix with pytest integration coverage.

Output: Both producer finally blocks evict the two dicts. Two integration tests prove `GET /{kind}/stream` returns 404 after the producer task completes.
</objective>
