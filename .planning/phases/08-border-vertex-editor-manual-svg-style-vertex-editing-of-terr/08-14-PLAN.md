`editableLayer='landmask'`, and there is no store state today that flips that. Fully
delivering LANDMASK-01/02 requires a new `editableLayer` store toggle + coord plumbing,
which is split into a dedicated Plan **08-16** (per the scope-reduction-prohibition:
split, don't simplify). This plan ships EDIT-POLYGON-01/02/03 at full fidelity.

    1. `const { data: branches = [] } = useBranches(projectId)`.
    2. `const activeBranchId = useEditorStore((s) => s.activeBranchId)`.
    3. useEffect with deps `[branches, activeBranchId]`:
       ```ts
       if (activeBranchId) return                 // user already has a branch
       if (!branches || branches.length === 0) return
       const persisted = loadPersistedActiveBranchId()
       const match = persisted ? branches.find((b) => b.id === persisted) : undefined
       const main = branches.find((b) => b.is_main) ?? branches[0]
       const chosen = match ?? main
       if (chosen) useEditorStore.getState().setActiveBranchId(chosen.id)
       ```
    Return null. Top doc comment: closes the GAP-B branch-init defect — VertexEditLayer
    polygon ops require a non-null branchId; without auto-select the editor stays dead
