<objective>
Add the **condado picker widget** (D-26): a dropdown that lets the Game Designer assign the new enclave's condado at
carve time, defaulting to the parent barony's condado when left unset. This is the LAST piece of the carve UX —
07 delivered the carve geometry + parent-default assignment, 08 delivered freehand + buttons + auto-select, and 09
lets the user OVERRIDE the inherited condado.

DATA-SOURCE DECISION (resolved concretely, with justification):
**Option (a) — add an additive `"idx"` field to territories.geojson.** Justification:
- The picker needs `id + name + idx`, AND choosing a DIFFERENT condado must recompute `duchy_id`/`kingdom_id` from
  THAT condado (transitive, D-26), not inherit the parent's.
- `baronies.geojson` (option b) has `condado_idx` but NO condado name (only `condado_id`) and only carries duchy/kingdom
  for condados that happen to have baronies — it cannot feed a transitive recompute for an arbitrary chosen condado.
- `territories.geojson` already emits, per condado, `id` + `name` + `duchy_id` + `kingdom_id` (canvas_sidecars.py:131-143),
  and the enumerate index `ci` EQUALS the barony's `condado_idx`. Adding `"idx": ci` makes it the complete single source.
- territories.geojson is a Phase-03 canvas sidecar, NOT one of the 12 Unity-contract files; the only parity assertion
  on it (tests/parity/test_iberia_868_yaml.py:135-137) checks `type == FeatureCollection` and `len(features) > 0` —
  it is NOT byte-hashed and NOT field-shape-asserted, so an additive field is parity-safe (VERIFIED, see read_first).

Purpose: Without the picker, every carved enclave inherits the parent's condado (07 default). The picker is the
user-facing override the live UAT asked for — "pick a different condado for the new barony."

Output:
- `canvas_sidecars.py` — additive `"idx": ci` on each territories.geojson condado feature + unit test.
- `useCanvasArtifacts.ts` — surface idx + duchy_id + kingdom_id to the frontend.
- `CondadoPicker.tsx` — Radix Select dropdown; emits {condado_idx, duchy_id, kingdom_id} or null (parent default).
- `PenDrawLayer.tsx` — wire the picker value into the carve payload's barony_meta override.
- 1 vitest spec + 1 real-mouse Playwright UAT (pick a DIFFERENT condado → reload → assert it stuck).

Scope NOTE (do NOT widen): the carve geometry/op (07) and freehand/buttons/auto-select (08) are done. This plan ONLY
adds the picker + the additive idx field + the transitive recompute. Do not touch the carve geometry. Do not reduce
the assignment to a stub — the default-to-parent path stays fully functional when the picker is unset.
