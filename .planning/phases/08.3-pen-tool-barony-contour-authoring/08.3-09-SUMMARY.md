# Phase 08.3 Plan 09: Condado picker (assign carved enclave's condado, transitive hierarchy) Summary

**A Radix Select dropdown (sourced from an additive, parity-safe `idx` field on territories.geojson) lets the Game Designer assign a carved enclave's condado at carve time; a chosen condado recomputes duchy/kingdom transitively (D-26), and leaving it unset defaults to the parent's condado.**

## Performance
- **Tasks:** 5 automated (1–5) + Task 6 human-verify checkpoint (approved by user)
- **Completed:** 2026-06-01

## Accomplishments
- Additive `"idx": ci` on every territories.geojson condado feature (`canvas_sidecars.py`) — `ci` = enumerate index = barony `condado_idx`. 3 unit tests GREEN (incl. the skipped-condado fixture proving idx == ORIGINAL cfg.condados index, not emitted-array position).
- `useCanvasArtifacts.ts` surfaces `idx` / `duchy_id` / `kingdom_id` on `TerritoryRender` and `condado_idx` on `BaronyRender` (additive, frontend-only — no parity impact).
- `CondadoPicker.tsx` — Radix Select listing condados (name + idx), de-duped by id; emits the chosen condado's `{condado_idx, duchy_id, kingdom_id}` (transitive) or `null` (parent default). 9 vitest GREEN.
- Wired into the carve commit flow: `CanvasViewer` hosts the picker in its DOM overlay, holds `pickedCondado` + `parentCondadoIdx`; `PenDrawLayer` fires `onParentCondadoChange` and reads `pickedCondado` in `commitCreate` to override `barony_meta` when set (parent default otherwise).
- Real-mouse Playwright UAT `08.3-condado-picker.spec.ts`: draw enclave → pick a DIFFERENT condado → Apply → reload → assert territory_metadata reflects the chosen condado (not the parent's). Real `page.mouse`, zero `__forge*` hooks.
- User confirmed live (Task 6): picked condado honored with transitive duchy/kingdom, persists on reload, unset still inherits the parent.
