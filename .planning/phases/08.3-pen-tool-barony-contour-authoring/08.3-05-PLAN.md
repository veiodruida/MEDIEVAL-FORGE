<objective>
The pen-draw interaction layer — the visible feature. A new `PenDrawLayer` Konva component (z=6,
component-local state mirroring BezierEditLayer) implements the Photoshop pen model: click = straight
anchor, click-drag = curve handle, close on first anchor, Esc discards, mid-draw Ctrl+Z per-anchor.
On close it flattens the path, infers country (Plan 04 endpoint) + inherits hierarchy from the snap
neighbor (Plan 02 fields), runs D-17 validation, and commits ONE `create` EditOp (Plan 03 contract).
EXTEND is inferred when the first anchor snaps to an existing contour and grafts via standard
add/move vertex ops — reusing the 08.2 replay path verbatim (Plan 01 proved no new backend op).

Depends on Plan 02 (hierarchy fields on baronies), Plan 03 (store/palette/keyboard contract), Plan 04
(create handler + country endpoint). This plan is the consumer that wires them together.

Purpose: PEN-CURVE-01 (pen feel), PEN-CREATE-01 (commit create op), PEN-EXTEND-01 (graft), and
PEN-ASSIGN-01 (D-08 country + D-09 inherit) all land here at the UI layer.
Output: snapToEdge + penFlatten libs, PenDrawLayer, and CanvasViewer/WorkspaceToolbar wiring.
</objective>
