#### 2. HydroSHEDS Iberia Basin Visual (SC#2)

#### 3. DEM Download + Ridge Visual (SC#3)

**Test:** Trigger `POST /api/projects/{id}/terrain/dem` to download Copernicus tiles; then trigger `POST /api/projects/{id}/terrain/ridges?sensitivity=med`; load `raw/ridges.geojson` in QGIS.
**Expected:** `raw/dem.tif` exists as valid GeoTIFF (EPSG:4326, int16, nodata=-32768). SSE stream shows "cache hit" on second run. `raw/ridges.geojson` has at least 1 ridge polygon polygon over Pyrenees and at least 1 over Sierra Nevada. Ridge IDs are stable across two consecutive runs.
**Why human:** Requires downloading real ~150MB of Copernicus tiles; ridge polygon coverage over specific mountain ranges requires visual geographic inspection.

#### 4. UI Re-trigger Semantics (SC#4)

**Test:** With a completed Overpass run (badge shows "pronto"), click "Executar" again on the Overpass StepCard. While running, click "Parar ingestão" and confirm it stops.
**Expected:** Badge transitions `pronto → rodando` on re-trigger; shared log panel clears and shows new progress lines; after completion badge returns to `pronto`; clicking Parar during run transitions badge to `pendente`. Running HydroSHEDS step independently does not affect the Overpass step's state.
**Why human:** UI state machine behavior requires real SSE stream interaction; cannot be fully covered by JSDOM-based unit tests.

### Notes on Accepted Deviations

**Plan 03: EU shapefile instead of global**
Summary 03 documents that the user downloaded `hybas_eu_lev06_v1c` (Europe-only, ~smaller) instead of the planned global `hybas_lev06_v1c`. For the current Iberia-focused use case (Reconquista 868 AD) this is fully acceptable. Non-European projects will produce empty `basins.geojson` silently. This is a known, accepted deviation documented in the plan summary.

**Plan 01: Router prefix convention**
The router uses `prefix="/projects/{project_id}/terrain"` (no `/api` prefix) and is registered with `prefix="/api"` in `main.py`, matching the existing router convention. This is a correct deviation from the plan's draft snippet.
