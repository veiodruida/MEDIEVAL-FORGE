# Phase 07.2 — Cloud LLM Providers + .env Import

Closes the research/LLM consolidation loop started in 07.1.

## Goal

Take the local-only research tool (Ollama + llama.cpp + Anthropic) and grow it
into a six-provider surface that a Game Designer can configure once via a
`.env` file and reuse across sessions. Surface the model's output live, make
failure modes actionable (not opaque httpx tracebacks), and keep the research
button reachable from every inspector mode.

## Why now

- **User feedback (UAT 2026-05-22 → 2026-05-23)** — "Quero poder ver o
  output do modelo bem como o seu processamento" + "deves oferecer outros
  modelos allem de antripic" + "Deve ser sempre possivel chamar a ferramenta".
- The local-only path discouraged casual exploration; free OpenRouter +
  Gemini tiers let a designer probe the tool without provisioning a paid
  account or downloading a 4 GB GGUF.

## What shipped

### Cloud providers (3 new)

1. **OpenRouter** (`openrouter.py`) — single API key reaches hundreds of
   models; `:free` suffix flags throttled but no-cost variants. `health()`
   queries `/models` and filters to live entries via
   `supported_parameters` ∋ `max_tokens` AND `architecture.output_modalities`
   ∋ `text`. Static whitelists were dropped after they drifted (Google
   retired `gemini-2.0-flash-exp:free`). Transient upstream 5xx are retried
   once with a 2 s backoff.
2. **OpenAI direct** (`openai_provider.py`) — `OPENAI_API_KEY`-backed
   `/chat/completions`. `health()` filters `/models` to chat families
   (`gpt-`, `o1-`, `o3-`).
3. **Gemini** (`gemini.py`) — Google AI Studio `v1beta` REST. `health()`
   keeps only `gemini-*` families with `generateContent`, dropping
   `antigravity-preview-*`, `*-tts-*`, and `*-audio-*` that 404 on chat.
   Pro > Flash > rest ranking so the default is sensible.

All three follow LlamaCpp's streaming + heartbeat shape (token envelopes,
2 s progress heartbeats, finish_reason termination) and surface PT-BR
actionable errors for 401 / 402 / 404 / 429 / 5xx.

### .env workflow

- `dotenv_import.py` exposes `parse_dotenv()` + `auto_discover_paths()` +
  `discover_dotenv_keys()`. Known env vars: `ANTHROPIC_API_KEY`,
  `OPENROUTER_API_KEY`, `OPENAI_API_KEY`, `GOOGLE_API_KEY` /
  `GEMINI_API_KEY`. Override via `MEDIEVAL_FORGE_DOTENV_AUTO_PATHS`.
- `main.py` lifespan calls `discover_dotenv_keys()` then `store_credentials()`
  with a non-overwriting merge — DB rows always win over auto-import.
- `api/v3/credentials.py` adds:
  - `GET /` rich status (`has_key`, `source: db|env|none`)
  - `PUT /{provider}` with `{ key }`
  - `DELETE /{provider}`
  - `POST /import` for a .env text blob
  - `GET /discover` (GET avoids wildcard `/{provider}` collision)

### Frontend

- `useCredentials.ts` — TanStack hooks for list/set/delete/import/discover.
- `CredentialsManager.tsx` — Radix dialog: file input + paste textarea +
  "Buscar .env do sistema" + per-provider masked TextField with Salvar /
  Remover.
- `ProviderSelector.tsx` — search filter when >8 models, `free` badge for
  `:free` suffixes, fixed CLOUD_PROVIDERS allowlist for the Configure-key
  button (no triple-gated heuristic).
- `ResearchDialog.tsx` — mounts ModelOutputPanel + LogPanel +
  ResearchResultPanel + CredentialsManager; removed auto-close so the user
  can read the result. Invalidates overlay query on terminal success.
- `ModelOutputPanel.tsx` — live token stream with elapsed counter and
  fallback to the latest progress heartbeat while no token has landed.
- `ResearchResultPanel.tsx` — post-success summary grouped by kingdom_owner.
- `InspectorSidebar.tsx` — persistent research trigger injected in every
  branch (placeholder / multi / barony / single / no-condado) with badge
  "N condados aplicados" once the overlay sidecar lands.

## Lessons paid for in hours

- **Streaming heartbeat first** — fire a heartbeat envelope *before* the
  first `asyncio.sleep(2.0)` so the UI leaves the "(aguardando primeiro
  token…)" placeholder within the first frame. Without it users assumed
  the request was stuck.
- **`num_ctx=32768 + num_gpu=999` blows 8 GB VRAM** on a 7B model and
  Ollama Desktop swallows the stderr; daemon either crashes silently or
  hangs. Drop the aggressive overrides — let Ollama auto-pick. Keep
  `num_predict=24576` (only setting we *can't* let the model author
  decide for our 15-25 k JSON output).
- **Schema-aware empty content** — qwen2.5:0.5b / llama3.2:1b under
  schema-constrained sampling sometimes finish with no text at all.
  `parse_research_json` then blows up with the opaque
  `EOF while parsing a value at line 1 column 0`. Catch upstream and
  surface "modelos muito pequenos frequentemente falham…" with a pull
  hint.
- **Static OpenRouter whitelists drift** — model ids change every few
  weeks. The live `/models` response carries `supported_parameters`
  exactly when at least one provider is alive for the entry; that's the
  truth source.
- **Antigravity / preview-tts / audio Gemini variants** all 429 or 404
  on chat. Filter by name fragment.
- **OpenRouter 402 even on `:free`** — accounts without any top-up are
  blocked from `:free` quota to prevent abuse. Surface the credits-page
  hint, not a generic "HTTP 402".
- **Bypass UI for regression UAT** — the MCP harness drove the SSE
  contract end-to-end in seconds. Browser_click flows would have taken
  minutes per provider and missed flakiness from upstream 502s.
- **Persistent research trigger** — inspector mode-gating hid the
  Configure-research button as soon as the user selected a condado. The
  fix was a single JSX block injected in every mode branch.
