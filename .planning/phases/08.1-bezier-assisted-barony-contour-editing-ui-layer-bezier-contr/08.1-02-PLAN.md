<objective>
Create `BezierEditLayer.tsx` as a Konva Layer that, on entry (barony selected + V-tool + baronies layer), fits the polygon to Béziers, builds the anchor display state in component-local state, and renders the curve outline + anchor squares + (active-anchor-only) control handles and tethers. Click-to-activate switches the active anchor. **No drag handler writes to the store in this plan.** Author and pass BEZ-IDENTITY-01 here — the empty-log identity contract — so it is GREEN before any drag-commit code exists (Plan 03).

Because this plan contains zero `setVerticesAndLog` calls, the identity test passes trivially by construction — proving the design cannot silently rewrite geometry. Plan 03's drag code can only land if this test stays green (RESEARCH §Identity Contract, Pitfall 1; UI-SPEC Note #2).
Output: `BezierEditLayer.tsx` (render + activate only), its render tests (BEZ-RENDER-01/02), the identity test (BEZ-IDENTITY-01), and a DEV-only `window.__forgeBezierState` escape hatch for Plan 04's Playwright reachability spec.
