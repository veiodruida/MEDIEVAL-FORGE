# Phase 08.1 Plan 02: BezierEditLayer render + identity contract Summary

**`BezierEditLayer.tsx` — a Konva Layer (z=5) that fits the selected barony's polygon to cubic Béziers on entry and renders the curve outline + ~4 anchor squares (NOT ~100 raw vertices) + active-anchor-only control handles/tethers, with all display state held component-local; the BEZ-IDENTITY-01 byte-identity guard lands here and is GREEN by construction because no drag-commit code exists yet.**

This matches the Plan 01 calibration (4 cubics).

## Identity contract (BEZ-IDENTITY-01)

The identity test mounts the **real** `BezierEditLayer` against the **real** `useEditorStore` (react-konva mocked because jsdom has no `canvas` dep — the fit-on-entry effect still runs, which is the path under test). Enter + exit Bézier edit mode with zero drags leaves:
- `JSON.stringify(useEditorStore.vertices)` byte-identical (exact match)
- `editLog.length` unchanged (0 → 0; no phantom entries)

It passes **by construction**: this plan contains zero `setVerticesAndLog` calls, so the store can never be silently rewritten. The drag-commit plan can only land while this test stays green.
