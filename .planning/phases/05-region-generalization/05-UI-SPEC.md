# Phase 05 — UI Design Contract

> Visual and interaction contract for the `NewProjectModal` surface (region-selection on create). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Scope: ONE new frontend surface — `NewProjectModal` (Radix `Dialog.Root` shell + project-name `TextField` + region `Select.Root`). Triggered by the existing "Novo projeto" button on `ProjectList`. Replaces the navigation-to-`/projects/new` flow ONLY when the region-selection variant is used; the legacy `ProjectNew.tsx` page (Wikidata QID/period/bbox autocomplete) stays untouched. Per CONTEXT.md D-07 + Phase 05 frontend-surface block.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn not applicable — project standardized on Radix UI Themes) |
| Preset | not applicable |
| Component library | `@radix-ui/themes` 3.x (Dialog, Select, TextField, Button, Flex, Box, Text, Callout) + `@radix-ui/react-toast` (already mounted in `main.tsx`) |
| Icon library | none (no icons in this surface — Radix Themes glyphs only if needed; do not introduce a new icon dependency) |
| Font | Radix Themes default stack (system UI fallback) |

Project-wide Radix Theme config (locked in `main.tsx`, do NOT override per-component):
- `appearance="light"`
- `accentColor="iris"`
- `radius="medium"`

CSS load order (`index.css`): Radix Themes styles BEFORE Tailwind v4 (`@import "@radix-ui/themes/styles.css"` then `@import "tailwindcss"`). Inline styles use Radix CSS variables (`var(--accent-9)`, `var(--gray-6)`, `var(--green-1)`, etc.) — never raw hex.

## Spacing Scale

Declared values (Radix Themes spacing scale `1..9` aligns to a 4px grid; this surface uses `1`..`6`):

| Token | Radix prop | Value | Usage |
|-------|------------|-------|-------|
| xs | `gap="1"` / `p="1"` | 4px | Stacked label + input pair gap |
| sm | `gap="2"` / `p="2"` | 8px | Inline button row, callout internal padding |
| md | `gap="3"` / `p="3"` | 12px | Form field-to-field vertical rhythm inside the dialog body |
| lg | `gap="4"` / `p="4"` | 16px | Dialog body padding, section breaks |
| xl | `p="5"` | 24px | Dialog outer padding (matches Radix `Dialog.Content` default) |
| 2xl | `p="6"` | 32px | Not used in this surface (reserved for page-level layout — e.g. `ProjectList`) |

Exceptions: dialog max-width clamped to `480px` (`style={{ maxWidth: 480 }}`) so the surface stays a focused single-task modal (project name + region) and does not visually compete with the workspace canvas behind it. Touch targets: Radix `Button` and `Select.Trigger` default to >= 32px height with `size="2"`; modal CTAs use `size="2"` (no exception needed).

## Typography

Use Radix Themes `<Text>` / `<Heading>` props exclusively. No raw `font-size` CSS. Three sizes + one heading; two weights.

| Role | Radix prop | Computed size | Weight | Line Height | Where |
|------|-----------|---------------|--------|-------------|-------|
| Body | `<Text size="2">` | 14px | `weight="regular"` (400) | 1.5 (Radix default) | Dialog description, region-disabled tooltip body, helper hints |
| Label | `<Text size="2" weight="medium">` | 14px | `weight="medium"` (500) | 1.5 | Form field labels ("Nome do projeto", "Região") |
| Heading | `<Heading size="4">` | 18px | `weight="bold"` (600 in Radix Themes) | 1.25 | `Dialog.Title` — "Novo projeto" |
| Caption | `<Text size="1" color="gray">` | 12px | `weight="regular"` (400) | 1.4 | Region option subtitle (bounds), `has_dataset: false` warning microcopy, validation hints |

Weights declared: `regular` (400) + `medium` (500). `bold` appears ONLY inside the `Heading` component as Radix's bundled token — not a third weight in the contract. Do not introduce `weight="bold"` on `<Text>` in this surface.

Body line-height: 1.5 (Radix default). Heading line-height: 1.25 (Radix default for `size="4"`). Do not override.

## Color

60/30/10 split via Radix Themes color tokens (resolved against the locked `accentColor="iris"` + `appearance="light"`).

| Role | Radix token / value | Usage |
|------|---------------------|-------|
| Dominant (60%) | `var(--color-panel-solid)` (white in light mode) | `Dialog.Content` background, `TextField.Root` background, `Select.Trigger` background |
| Secondary (30%) | `var(--gray-2)` + `var(--gray-6)` borders | Disabled `Select.Item` background, Dialog overlay backdrop (Radix default `rgba(0,0,0,0.4)`), helper-text region |
| Accent (10%) | `var(--accent-9)` (iris-9) | Primary CTA fill ("Criar projeto" `Button`), focus ring on `TextField` + `Select.Trigger`, selected option indicator in `Select.Content` |
| Destructive | `var(--red-9)` | NOT used in this surface — no destructive actions in NewProjectModal. Cancel is a soft secondary, not destructive. (Reserved at project level for the existing delete-project button on `ProjectList`.) |
| Warning / disabled-dataset | `var(--amber-9)` text on `var(--amber-2)` background | `has_dataset: false` region rows (England 1216) — disabled state + tooltip/microcopy hint |

Accent reserved for:
1. Primary CTA fill (`<Button>` "Criar projeto" — Radix default uses accent automatically; do not override `color`)
2. Focus rings on `TextField.Root` and `Select.Trigger` (Radix Themes default behavior; do not override)
3. Selected/highlighted option in `Select.Content` (Radix default)

Accent is NOT used for:
- Body text
- Borders (use `var(--gray-6)` / `var(--gray-7)`)
- Hover backgrounds on non-CTA buttons (Radix `variant="soft"` already handles this in a neutral tone for the "Cancelar" button)
- The "Anterior" preview badge from Phase 04.1 (out of scope here)

## Interaction Contract

Beyond the design tokens, the executor must implement these locked interaction behaviors:

| Behavior | Spec |
|----------|------|
| Trigger | "Novo projeto" button on `ProjectList` page (existing). Phase 05 swaps the `<Link to="/projects/new">` wrapper for a `Dialog.Trigger` so the modal opens in-place. The `/projects/new` route + legacy `ProjectNew.tsx` page remain mounted for now (do not delete in Phase 05 — out of scope; the legacy page handles Wikidata QID flows that the modal does not). |
| Initial focus | `Dialog.Content` autofocuses the project-name `TextField` on open (Radix default). |
| Default selected region | `iberia_868` — controlled `Select.Root` `defaultValue="iberia_868"`. If the regions list does not contain `iberia_868` (degenerate config), fall back to the first `has_dataset: true` region; if none, fall back to the first item (which renders disabled and prevents submit). |
| `has_dataset: false` rows | Rendered with `<Select.Item disabled>` so they appear greyed but selectable-looking; clicking does nothing (Radix handles). Suffix `(sem dataset)` appended to label. Helper text under the field reads the tooltip copy when such an item is focused. |
| Submit validation | Project name: trimmed length ∈ [1, 64]. Region: must be a key present in the most-recent `useRegions` response AND `has_dataset: true`. Submit button disabled until both conditions pass. |
| Submit action | `POST /api/v3/projects` with body `{name: string, region_key: string}`. On success, close dialog, invalidate `useProjects` query (TanStack Query), navigate to `/projects/{id}`. On 4xx/5xx, keep dialog open, render inline error copy (see Copywriting), do not navigate. |
| Cancel / dismiss | `Cancelar` button, ESC key, click on `Dialog.Overlay` — all close the dialog and discard in-memory form state without confirmation. No "unsaved changes" prompt (state is trivial). |
| Loading skeleton | While `useRegions.isLoading`, render the `Select.Trigger` disabled with the "Carregando regiões..." copy. Do NOT render a spinner inside the field — Radix `<Spinner>` allowed in the trigger if a single visual cue is needed (executor's choice; do not stack two cues). |
| Error fallback | `useRegions.isError` triggers a `@radix-ui/react-toast` notification using the existing Toast Provider. Dialog stays open with `Select.Trigger` disabled. Retry CTA inside the toast calls `useRegions.refetch()`. |
