       ```python
       """Plugin registry for LLM providers.

       D-05: Phase 07 ships exactly 2 providers (Claude + Ollama). OpenAI + Gemini
       slots are intentionally absent — see .planning/backlog.md v3.1 deferrals.

       Discretion #10: import-time population. Predictable startup behavior;
       trivial cost for 2 adapters.

       To add a v3.1 provider: import the class here, add one line to PROVIDERS.
       """
       from __future__ import annotations

       from .base import LLMProvider

       # PROVIDERS is populated by services/llm/__init__.py AFTER claude.py + ollama.py
       # are imported (Plan 04). This avoids a circular import: registry.py is part of
       # the package init order; ClaudeProvider depends on credential_store which
       # transitively depends on models, which the FastAPI app loads via database.py.
       PROVIDERS: dict[str, LLMProvider] = {}


       def register(provider: LLMProvider) -> None:
           """Add a provider to the registry. Called by services/llm/__init__.py."""
           PROVIDERS[provider.provider_id] = provider


       def get(provider_id: str) -> LLMProvider | None:
           return PROVIDERS.get(provider_id)


       def list_providers() -> list[LLMProvider]:
           return list(PROVIDERS.values())
       ```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-01 | DoS | retry loop max_retries | mitigate | 3-retry hard cap (literal-port retry.py) prevents infinite loops. Acceptance criterion: `test_run_with_retry_raises_after_3_consecutive_validation_errors` proves the cap. |
| T-07-03-02 | Tampering | retry.py PT-BR strings | accept | Pitfall 9 documents this as intentional; frontend tolerates both shapes. Reviewers must not "fix" the language. |
| T-07-03-03 | Information Disclosure | retry.py error-in-prompt feedback | accept | Error messages echoed into retry prompts may leak partial LLM internals into the next LLM call — by design, since the LLM is the one trusted to read its own error and correct. No human-readable secrets flow through retry.py. |
| T-07-03-04 | Tampering | registry deferred population | mitigate | `PROVIDERS == {}` at Plan 03 end; Plan 04's __init__ update is gated by an acceptance criterion (`len(PROVIDERS) == 2` after Plan 04 lands). Empty registry consumers (Plan 07 runner) error out with clear "no provider registered" instead of silent fallthrough. |
