# Phase 07 — UI Design Contract

> Visual and interaction contract for the LLM research opt-in metadata layer + the absorbed Phase 06 export-error surface. Generated by gsd-ui-researcher; verified by gsd-ui-checker.

Scope — **three distinct frontend surfaces** introduced or extended in Phase 07:

1. **`ResearchDialog` (NEW)** — Radix `Dialog.Root` modal that runs the SSE research flow (`ProviderSelector` + `ResearchProgress` sub-components inside it). Trigger lives in `InspectorSidebar` placeholder mode per CONTEXT D-08.
2. **`InspectorSidebar` extensions (MODIFIED)** — placeholder-mode gains a "Pesquisar metadados históricos" button; condado / barony modes gain a "Pesquisa aplicada" badge when the overlay covers the selected territory.
3. **`ExportErrorDialog` (NEW — Phase 06 absorption, CONTEXT D-10)** — renders the structured 422 envelope from `POST /api/v3/projects/{id}/export` with PT-BR strings for **six** stable error codes. Triggered when the existing "Exportar ZIP" button in `WorkspaceToolbar` posts and receives 422.

Out of scope for this contract (deferred / out-of-phase): drag-and-drop condado re-assignment, manual overlay JSON editor, token usage UI, multi-turn LLM refinement, OpenAI/Gemini providers (registry slots only — no UI), at-rest credential encryption, NewProjectModal redesign (Phase 05 contract still authoritative).

## Spacing Scale

Declared values (multiples of 4 only — Radix Themes spacing scale `1..9` aligns to a 4px grid; this phase uses `1`..`5`):

| Token | Radix prop | Value | Usage |
|-------|------------|-------|-------|
| xs | `gap="1"` / `p="1"` | 4px | Icon-to-label gap inside buttons; tight badge padding; per-stage row internal vertical rhythm in `ResearchProgress` |
| sm | `gap="2"` / `p="2"` | 8px | Inline button rows (Cancelar + Iniciar); badge-to-text inside an error row; checkbox-to-label gap |
| md | `gap="3"` / `p="3"` | 12px | Form field-to-field vertical rhythm inside `ResearchDialog` body; stage-row vertical rhythm in `ResearchProgress` |
| lg | `gap="4"` / `p="4"` | 16px | `Dialog.Content` body padding; section breaks inside the dialog; `InspectorSidebar` button block padding |
| xl | `p="5"` | 24px | `Dialog.Content` outer padding (Radix default for `Dialog.Content`); top-of-`ExportErrorDialog` heading-to-list gap |

Exceptions (justified for this phase):

- **`ResearchDialog` max-width clamped to `560px`** (`style={{ maxWidth: 560 }}`) — matches the v1-archive 03-UI-SPEC dialog width and avoids competing visually with the workspace canvas behind it. Form has 4 fields + a per-stage progress list; 480px (Phase 05 `NewProjectModal` width) is too narrow once the per-stage list expands.
- **`ExportErrorDialog` max-width clamped to `560px`** — same reason; each error row is `[code badge] · [file path] · [PT-BR message]` and 480px wraps the message awkwardly at typical file-path lengths (`territory_metadata.json`).
- **`ResearchProgress` per-stage list `maxHeight: 240px`** with vertical `ScrollArea` — prevents the dialog from growing past viewport on long runs (Iberia: 4 stages × N retries each).
- **Touch targets**: Radix `Button size="2"` and `Select.Trigger` default to ≥ 32px height; modal CTAs use `size="2"` (no exception needed). The `InspectorSidebar` "Pesquisar metadados históricos" button uses Radix default `size="2"` (matches the existing Inspector layout's compact rhythm).

Sources: `frontend/src/components/canvas/InspectorSidebar.tsx` (gap=3/p=3 pattern), `frontend/src/components/projects/NewProjectModal.tsx` (Dialog body gap=3 + p=4 mt=4), `frontend/src/components/canvas/ParameterSidebar.tsx` (Sidebar gap=4 p=4).

| Role | Radix prop | Computed size | Weight | Line Height | Where |
|------|-----------|---------------|--------|-------------|-------|
| Body | `<Text size="2">` | 14px | `weight="regular"` (400) | 1.5 (Radix default) | Dialog description, error-row PT-BR message, stage-row label, badge label inside Inspector, info text |
| Label | `<Text size="2" weight="medium">` | 14px | `weight="medium"` (500) | 1.5 | Form field labels ("País", "Período", "Provider", "Modelo"); checkbox label "Forçar nova pesquisa (ignorar cache)" |

Heading line-height: 1.25 (Radix default for `size="4"`). Body line-height: 1.5 (Radix default). Do not override either.

## Color

60/30/10 split via Radix Themes color tokens (resolved against the locked `accentColor="iris"` + `appearance="light"`). No raw hex.

| Role | Radix token / value | Usage |
|------|---------------------|-------|
| Dominant (60%) | `var(--color-panel-solid)` (white in light mode) | `Dialog.Content` background, `TextField.Root` background, `Select.Trigger` background, `Checkbox.Root` background, stage-row background |
| Secondary (30%) | `var(--gray-2)` panels + `var(--gray-6)` borders | Dialog overlay backdrop (Radix default `rgba(0,0,0,0.4)`), disabled `Select.Item` background, separator lines between sections, completed-stage row background (`var(--gray-2)`) |
| Accent (10%) | `var(--accent-9)` (iris-9) | Primary CTA fill ("Iniciar pesquisa" `Button` — Radix default; do NOT override `color`); focus rings on `TextField` + `Select.Trigger` + `Checkbox` (Radix default); selected option indicator in `Select.Content` (Radix default); active per-stage row left border in `ResearchProgress` (currently-streaming stage only) |
| Destructive | `var(--red-9)` (solid) + `var(--red-3)` (soft) + `var(--red-11)` (text) | "Cancelar pesquisa" button inside the modal when SSE stream is open (`color="red" variant="solid"` — matches `WorkspaceToolbar.tsx:93-99` cancel pattern); inline submission error message (`<Text size="2" color="red">`); error-code badge in `ExportErrorDialog` (`<Badge color="red" variant="soft">`) |
| Success feedback | `var(--green-9)` (soft badge) | "Pesquisa aplicada" badge in `InspectorSidebar` condado/barony mode; "Resultado em cache" badge inside `ResearchDialog` cache-status row; completed stage row in `ResearchProgress` shows a `CheckCircledIcon` colored `var(--green-9)` |
| Warning / disabled | `var(--amber-9)` text + `var(--amber-2)` background (tooltip) | `ProviderSelector` disabled option (Ollama unreachable, Claude unauthenticated) — appears greyed with an `ExclamationTriangleIcon` colored `var(--amber-9)` and a tooltip explaining the cause (see Copywriting) |

**Accent (`--accent-9`, iris) is reserved for and ONLY for:**

1. Primary CTA fill on "Iniciar pesquisa" inside `ResearchDialog` (Radix default — do NOT override `color`).
2. Focus rings on `TextField.Root`, `Select.Trigger`, `Checkbox.Root` (Radix default behavior).
3. Selected/highlighted option in `Select.Content` (Radix default).
4. The 2px left border on the currently-streaming stage row in `ResearchProgress` (visual progress indicator — single active stage at a time).

**Accent is NOT used for:**

- Body text (uses default `var(--gray-12)`).
- Borders on non-CTA elements (use `var(--gray-6)` for separators).
- Hover backgrounds on the "Cancelar" button or the `InspectorSidebar` research trigger (Radix `variant="soft"` already handles those neutrally).
- The "Pesquisa aplicada" or "Resultado em cache" badges (use `color="green"` — these are success signals, not accent).
- The "Cancelar pesquisa" button while a stream is active (uses `color="red"` — destructive signal trumps accent).

Sources: `frontend/src/main.tsx:19` (`accentColor="iris"` locked), `frontend/src/components/canvas/InspectorSidebar.tsx:111-117, 223-235` (`color="amber|blue|grass|gray"` badge pattern), `WorkspaceToolbar.tsx:93-100` (red cancel button), 07-RESEARCH.md §"Example 4" (red error-code badge), v1-archive 03-UI-SPEC §Color (amber/green semantic conventions inherited).

### Surface 3 — `ExportErrorDialog` (Phase 06 absorption)

`POST /api/v3/projects/{id}/export` returns 422 with the envelope `{ summary: string, errors: ValidationErrorEntry[] }`. Each entry carries `{ code, severity, file, context, message }`. The dialog renders one row per error with the **stable PT-BR string keyed by code**.

| Element | Copy (PT-BR) |
|---------|------|
| `Dialog.Title` | `Falha ao exportar` |

| Error row layout | `[<Badge color="red" variant="soft">{code}</Badge>] · <Text size="1" color="gray">{file}</Text> · <Text size="2">{EXPORT_ERROR_PT_BR[code]}</Text>` |

| Dry-run report — passed state body | `Nenhum problema encontrado. Clique em "Exportar" no painel principal para baixar o ZIP.` |

| `TERRITORY_TOO_SMALL` | `Território com menos de 200 pixels — abaixo do mínimo do contrato.` |
