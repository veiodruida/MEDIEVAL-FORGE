## Spacing Scale

Declared values (multiples of 4). Radix Themes prop notation in parentheses.

| Token | Value | Radix prop | Usage |
|-------|-------|------------|-------|
| xs | 4px | `gap="1"` / `p="1"` | Icon gaps, badge internal spacing |
| sm | 8px | `gap="2"` / `p="2"` | Compact element rows, floating overlay padding |
| md | 16px | `gap="3"` / `p="3"` | Default card padding, inspector sections |
| lg | 24px | `gap="4"` / `p="4"` | Section breaks inside inspector |
| xl | 32px | `gap="5"` | Layout gaps between toolbar regions |
| 2xl | 48px | — | Major section breaks (not used in this phase) |
| 3xl | 64px | — | Page-level spacing (not used in this phase) |

Exceptions:
- Toolbar height: 48px (not a standard spacing token — structural dimension)
- Inspector sidebar width: 320px (structural dimension per D-01)
- Floating overlay anchors: `top: 12px`, `left: 12px` (matches existing LayerTogglePanel + LegendCard)
- Touch targets (buttons): minimum 36px height

## Typography

Radix Themes uses a size scale (`size="1"` through `size="9"`) rather than raw px. Map below is authoritative for new Phase 03 chrome; existing components are reused verbatim.

| Role | Radix Size | Approx px | Weight | Line Height | Usage |
|------|-----------|-----------|--------|-------------|-------|
| Caption | `size="1"` | ~11px | regular (400) | 1.5 | Label sub-text, coords, path breadcrumb |
| Body | `size="2"` | ~14px | regular (400) | 1.5 | Inspector rows, log entries, badge text |
| Label | `size="2"` | ~14px | bold (600) | 1.5 | Section headings inside inspector |

> Source: InspectorSidebar.tsx and LegendCard.tsx already establish size="1", size="2", size="3" usage. Match these exactly in new components.

Weights in use: regular (400) + bold (600). No other weights allowed in Phase 03 chrome.

## Canvas States

### EmptyCanvasState (D-05)

Position: absolute, centered within canvas area.

```
[Icon — @radix-ui/react-icons MagicWandIcon or SewingPinFilledIcon — 48px]
[Text size="3" weight="bold"]: "Gerar mapa medieval para [país] [período]"
[Text size="2" color="gray"]: "Nenhum mapa gerado. Clique em 'Gerar Mapa' para iniciar."
[Button color="blue" variant="solid" size="3"]: "Gerar Mapa"
```

- Icon size: 48px, `color="gray"` tone
- Vertical stack, centered, gap="4"
- [país] and [período] are interpolated from `project.country_qid` + `project.period_start`–`project.period_end` at runtime

### GeneratingCanvasState (D-07)

Position: absolute, centered within canvas area.

```
[Spinner or animated dots — amber color]
[Text size="2" color="gray"]: "Gerando mapa…"
[RunLogPanel — inline expanded]
```

RunLogPanel (D-03):
- Ordered list of 11 DAG stages in English (matching module names):
  `landmask → border → voronoi → cleanup → smooth → merge → hierarchy → render → lookup → metadata → export`
- Each entry: `Text size="1"` — `[✓ | ○ | ●]` glyph + stage name
  - Pending: `○` gray
  - Active: `●` amber (pulsing)
  - Done: `✓` grass/green
- Width: 280px, max-height: 300px
- Background: `var(--color-panel-solid)` Card, `p="3"`
- Gap between rows: `gap="1"` (4px)

### ErrorCanvasCallout (D-08)

Position: top of canvas area, full-width, not absolute — pushes canvas down.

```
[Callout.Root color="red" variant="surface"]
  [Callout.Icon] — ExclamationTriangleIcon
  [Callout.Text]:
    "Falha no estágio: [stage_name]"
    "[last_log_line]"
    [copyable error message — <code> block with copy button]
  [Button color="red" variant="soft"]: "Tentar novamente"
```

- Uses `Callout` from `@radix-ui/themes`
- Error message block: `<code>` with monospace font, background `var(--red-3)`, copyable via `navigator.clipboard`
- "Tentar novamente" button re-dispatches POST generate

## Interaction Contract

### Hover (D-15)

- On `mouseover` condado polygon in TerritoryLayer: paint 1px `#9ca3af` outline on a hover layer (or via Konva `stroke` on shape — planner decides implementation detail)
- Tooltip: `<div>` overlay (NOT Radix `Tooltip` — Radix cannot be portaled onto Konva Stage). Positioned via `Stage.getPointerPosition()`. Shows condado name. `Text size="1"`, `Card variant="surface"`, padding `4px 8px`, `z-index: 50`.
- Hover tooltip dismisses when pointer leaves the condado shape.

### Click selection (D-15 / D-16)

- Click condado → `useUIStore.select(id)` → InteractionLayer paints gold `#f0c040` 3px outline
- Click on water / empty Stage → `useUIStore.select(null)` → inspector returns to placeholder
- Canvas centers on selected condado (existing `panToGeoCenter` behavior in CanvasViewer)

### Multi-select (D-17)

- `Shift+click` adds condado to selection set
- `Shift+click` on already-selected condado removes it
- Click without Shift replaces selection with single territory
- Gold `#f0c040` 3px outline applies to ALL selected territories simultaneously
- `InteractionLayer` receives `selectedTerritoryIds: string[]` (new prop for multi-select); single-select is `selectedTerritoryIds = [id]`

### Multi-select Inspector aggregate (D-17, NEW)

When 2+ territories selected, InspectorSidebar shows a MultiSelectInspector view:

```
[Heading size="3"]: "X condados selecionados"
[Text size="2" weight="bold"]: "Área total"
[Text size="2"]: "[sum pixel_count converted to km²] km²"
[Text size="2" weight="bold"]: "Reinos"
[Flex gap="1" wrap="wrap"]: [Badge color="amber" variant="soft"] per unique kingdom
[Text size="2" weight="bold"]: "Ducados"
[Flex gap="1" wrap="wrap"]: [Badge color="blue" variant="soft"] per unique duchy
[Text size="2" weight="bold"]: "Condados"
[ScrollArea maxHeight="200px"]:
  [Text size="2"] per condado name, one per line
```

- "X condados selecionados" — X is the count interpolated at runtime
- No per-territory detail in multi-select view (single click required for D-14 detail)
- Deselect all: click without Shift on empty Stage

## Notes for Executor

1. `CanvasViewer.tsx` imports `useUndoShortcut`, `useEditKeyboardMap`, `useRubberBandSelection`, `SplitTool`, `useResearchStore`, `useEditorStore`, `useValidationStore`, `EditApiError` etc. — all deleted by D-10/D-11. The new `CanvasViewer` must purge these imports and their usage. The "reused as-is" contract means the **read-only behavior** is preserved, not the file's current contents verbatim. The planner must create a stripped version.

2. The `COPY` const in `InspectorSidebar.tsx` contains English strings that are test-asserted. Do not translate `PROJECT_OVERVIEW`, `PATH_LABEL`, `CENTROID_LABEL`, `CAPITAL_LABEL`, `ADJACENT_LABEL`, `NO_CAPITAL`, `NO_NEIGHBORS`. New strings from this phase's Phase 03 chrome are PT-BR.

3. Hover tooltip for D-15 is a `<div>` overlay positioned via `Stage.getPointerPosition()` — Radix `Tooltip` cannot portal onto Konva Stage without a DOM node as anchor. Use `position: absolute; pointer-events: none; z-index: 50`.

4. The `InteractionLayer` currently only renders single-selection. Multi-select (D-17) requires a new prop `selectedTerritoryIds: string[]`. The existing `selectedTerritoryId: string | null` (from `useUIStore`) becomes the first element of the array in the single-select path.

5. `useCanvasArtifacts` fetches from `/api/projects/${projectId}/preview/...` (v1 path). Phase 03 switches to `/api/v3/projects/${projectId}/artifacts/...`. URL replacement only — data shapes are identical (Phase 01 already emits matching schemas).

6. The `GenerateStatusBadge` click target opens `RunLogPanel` inline — NOT a modal. Canvas remains interactive (visible but potentially obscured by the log panel). Log panel is a DOM overlay, not a Konva layer.

7. Cache-busting: append `?v=${project.updated_at}` to all artifact URLs (existing `cacheVersion` prop in `CanvasViewer`). `run_pipeline` updates `project.updated_at` after writing files (D-19).
