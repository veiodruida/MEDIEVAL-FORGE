1. **Add path-traversal guard inside `launch()` BEFORE any state mutation:**
   ```python
   def launch(model_filename: str) -> LaunchResult:
       # T-07.1-05-02 path-traversal mitigation (ASVS V12).
       # Reject any directory component, only accept basenames with .gguf suffix.
       if not model_filename:
           raise LlamacppInvalidModelFilename("model filename is empty")
       if Path(model_filename).name != model_filename:
           raise LlamacppInvalidModelFilename(
               f"model filename must not contain directory components: {model_filename!r}"
           )
       if Path(model_filename).suffix.lower() != ".gguf":
           raise LlamacppInvalidModelFilename(
               f"model filename must end with .gguf: {model_filename!r}"
           )
       resolved_dir = models_dir().resolve()
       target_path = (resolved_dir / model_filename).resolve()
       # Defense-in-depth: ensure resolved path is inside models_dir (handles symlinks).
       if resolved_dir not in target_path.parents and target_path.parent != resolved_dir:
           raise LlamacppInvalidModelFilename(
               f"model path escapes models dir: {target_path}"
           )
       if not target_path.exists():
           raise LlamacppModelNotFound(f"model not found: {target_path}")
       # ... continue with binary + popen
   ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP body → launcher.launch() | The `model` field of `POST /api/v3/llm/llamacpp/launch` body crosses from untrusted client to spawning `subprocess.Popen`. The router (plan 07.1-07) is the entry; this module enforces the security checks regardless of caller. |
| Env vars `MEDIEVAL_FORGE_LLAMACPP_MODELS_DIR` + `LLAMA_SERVER_BIN` → launcher | User-controlled local env; trust boundary is the developer's shell. Treated as trusted per PATH semantics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07.1-05-01 | Tampering (command injection) | `subprocess.Popen` argv | mitigate | `subprocess.Popen([binary, "-m", str(target_path), "--ctx-size", "8192", "--port", str(port)], shell=False, stdout=DEVNULL, stderr=DEVNULL)` — list form, never f-string into a shell. Filename never reaches a shell. Verified by `grep -c "shell=True"` = 0 acceptance criterion. |
| T-07.1-05-02 | Tampering / Info Disclosure (path traversal) | `launch(model_filename)` | mitigate | Three-layer guard: (1) `Path(model_filename).name != model_filename` rejects directory components; (2) `Path(model_filename).suffix.lower() != ".gguf"` rejects non-gguf; (3) resolved `(models_dir() / filename).resolve()` MUST be inside `models_dir().resolve()` — handles symlink escapes. Tests `test_launch_rejects_path_traversal_dotdot_filename`, `test_launch_rejects_filename_with_directory_component`, `test_launch_rejects_non_gguf_suffix` enforce. |
| T-07.1-05-03 | Elevation of Privilege | `LLAMA_SERVER_BIN` env var | accept | User controls own env; consistent with PATH semantics. Documented in module docstring. No validation possible without enumerating allowed binaries (would break legitimate user customization). |
| T-07.1-05-04 | DoS (port race) | `socket.bind(('', 0))` then close, then Popen | accept | D-08 explicitly accepts this race ("Race window is acceptable for single-user local app"). Pitfall 4 documents. If it becomes painful, follow-up plan can add retry-with-new-port. |
| T-07.1-05-05 | DoS (zombie process on parent crash) | `Popen` without persistent PID file | accept | D-08b: atexit fires on clean exit; hard crash orphans the process. Documented user-facing remedy: `taskkill /F /IM llama-server.exe` (Windows) or `pkill llama-server` (POSIX). |
| T-07.1-05-06 | DoS (pipe deadlock) | `Popen.stdout` / `Popen.stderr` | mitigate | `stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL` — Pitfall 8 mitigation. Verified by `grep -c "DEVNULL"` >= 2. |
| T-07.1-05-07 | Resource exhaustion (multiple concurrent processes) | Module-level `_PROCESS` singleton | mitigate | D-08 idempotency: only one process at a time; different-model launch raises `LlamacppLaunchConflict` (HTTP 409 surfaced by router in plan 07.1-07). |
</threat_model>
