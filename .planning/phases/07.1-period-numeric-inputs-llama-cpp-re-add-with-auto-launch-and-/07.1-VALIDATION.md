## Sampling Rate

- **After every task commit:** Run targeted test file (`pytest tests/unit/test_<x>.py` or `vitest run <x>`)
- **After every plan wave:** Run quick suite (unit + parity)
- **Before `/gsd-verify-work`:** Full suite must be green including Playwright UAT
- **Max feedback latency:** 30s (per-task) / 180s (per-wave) / 360s (full)
