Fix orphan bug #1 from `.planning/phases/04-canvas-editing-basic/04-HUMAN-UAT.md` (line 175):
the `vertex-handles` endpoint asks `decimate_polygon` for ~12 handles but receives the
full original vertex count (286 for lugo's 287-pt polygon). The Douglas-Peucker binary
search in `decimate_polygon` is effectively a no-op for real territory polygons because
its hard-coded `tolerance_range=(0.0, 1.0)` is wildly mis-scaled for lon/lat degree
coordinates of small condados (~0.5° span): every probe at the high end of the range
collapses the polygon into invalid geometry, the search bisects toward zero, and
`best` ends up barely simplified (or not at all). The endpoint then returns ~all
original vertices.

Replace the brittle DP binary search with a deterministic, scale-independent
**uniform-stride-with-corner-preservation** sampler:
1. Score every original vertex by local turning angle (high score = sharp corner).
2. Always keep the top-K highest-curvature vertices (K ≈ target / 2).
3. Fill the remaining (target - K) slots by uniform stride over the rest of the ring.
4. Reorder by original index to keep ring continuity, close the ring.

This guarantees `len(handles) ≈ target` for any input regardless of coordinate units,
preserves visually meaningful corners, and removes the dependency on `shapely.simplify`'s
tolerance heuristics.

Purpose: vertex-drag UX is currently unusable on real territories — 286 handles overlap
into a single dot at zoom-1, defeating the purpose of D-02's "decimated handles" design.

Output: corrected `decimate_polygon` + new regression test that fails on the current
implementation and passes on the fix.

    ```python
    def decimate_polygon(geometry: dict, target_vertices: int = 12, **_ignored) -> dict:
        """Reduce polygon to ~target_vertices, preserving high-curvature corners.

        Scale-independent (works for unit-square, lon/lat degrees, or pixels)
        because it operates on vertex INDICES, not metric tolerances. D-02 + EDIT-02.
        """
        polygon = _to_shapely(geometry)
        if not isinstance(polygon, Polygon):
            raise ValueError("decimate_polygon requires a Polygon geometry")

        coords = list(polygon.exterior.coords)[:-1]  # drop closing duplicate
        n = len(coords)
        if n <= target_vertices:
            return _to_geojson(polygon)

        # 1. Curvature score: |turning angle| at each vertex (cross product magnitude /
        #    product of segment lengths). Higher = sharper corner.
        scores = []
        for i in range(n):
            ax, ay = coords[(i - 1) % n]
            bx, by = coords[i]
            cx, cy = coords[(i + 1) % n]
            v1x, v1y = bx - ax, by - ay
            v2x, v2y = cx - bx, cy - by
            cross = abs(v1x * v2y - v1y * v2x)
            l1 = (v1x * v1x + v1y * v1y) ** 0.5
            l2 = (v2x * v2x + v2y * v2y) ** 0.5
            denom = l1 * l2
            scores.append(cross / denom if denom > 0 else 0.0)

        # 2. Always keep top-K highest-curvature vertices (K = target // 2).
        k_corners = max(2, target_vertices // 2)
        corner_indices = sorted(
            range(n), key=lambda i: scores[i], reverse=True
        )[:k_corners]
        keep = set(corner_indices)

        # 3. Fill remaining slots with uniform stride over the full ring,
        #    skipping indices already kept. Use floats to avoid stride drift.
        remaining = target_vertices - len(keep)
        if remaining > 0:
            stride = n / target_vertices
            for j in range(target_vertices):
                idx = int(round(j * stride)) % n
                if idx not in keep:
                    keep.add(idx)
                    if len(keep) >= target_vertices:
                        break

        # 4. Sort by original index to preserve ring orientation; close ring.
        ordered = sorted(keep)
        new_coords = [coords[i] for i in ordered]
        new_coords.append(new_coords[0])

        new_poly = Polygon(new_coords)
        # Topology safeguard — if the sampling produces self-intersection
        # (extremely rare for convex-ish Voronoi cells), fall back to plain stride.
        if not is_valid(new_poly):
            stride = max(1, n // target_vertices)
            fallback = [coords[i] for i in range(0, n, stride)][:target_vertices]
            fallback.append(fallback[0])
            new_poly = Polygon(fallback)
        return _to_geojson(new_poly)
    ```
