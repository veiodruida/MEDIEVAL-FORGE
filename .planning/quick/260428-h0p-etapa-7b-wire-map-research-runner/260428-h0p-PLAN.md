<objective>
Etapa 7b (deferred from Etapa 7 SUMMARY out_of_scope): finish wiring the
MapResearchResult / barony_assignments path end-to-end:

1. research_runner.run_research uses build_map_research_prompt + MapResearchResult
   schema when the project has raw/baronies.geojson on disk; otherwise keeps the
   legacy ResearchResult flow byte-identical.
2. The _ValidatingWrapper on the map-path runs validate_barony_assignments after
   each provider call, so the retry loop re-prompts when the LLM emits unknown
   or incomplete barony assignments.
3. build_territory_data_from_cache dispatches by payload shape: payloads with
   `barony_assignments` go through assemble_territory_data_from_baronies (Etapa 7),
   payloads with the legacy `baronies` dict keep going through assemble_territory_data.

After this step, the full new pipeline is plumbed: ingest OSM → baronies builder
→ research with assignments → cached MapResearchResult → generate via aggregator.
</objective>
