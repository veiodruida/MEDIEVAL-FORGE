<objective>
Fix two research-flow bugs observed after shipping the manual provider:

1. **Dates don't persist.** Editing `period_start` / `period_end` inside the ResearchDialog is lost the moment the user closes the dialog — the values only live in the Zustand research store and are never PATCHed to the Project row. The LLM flow streams against the stale DB values; the manual-prompt flow builds its prompt from the stale DB values.
2. **Multi-country is impossible.** `ProjectCreate/Update.country_qid` resolves a single value via `resolve_to_qid`, which rejects `"Q29,Q45"`. The DB column is `String(20)` and cannot store the comma list anyway. Péninsula Ibérica preset therefore ships with `country_qid="Q29"` only, so ingestion clips against Spain without Portugal.

Purpose: research outputs must match what the user sees on screen (dates they typed, countries they picked).
Output: DB schema + validator + preset updated; frontend PATCHes before every research call.
</objective>

    ```python
    def _resolve_country_list(v: str) -> str:
        """Accept 'Q29', 'Espanha', or 'Q29,Q45' / 'Espanha,Portugal'.
        Returns the canonical comma-separated QID string (no spaces).
        Raises ValueError if ANY token fails to resolve.
        """
        tokens = [t.strip() for t in v.split(",") if t.strip()]
        if not tokens:
            raise ValueError("country_qid não pode ser vazio")
        qids = [resolve_to_qid(t) for t in tokens]
        # Deduplicate while preserving order
        seen: set[str] = set()
        out: list[str] = []
        for q in qids:
            if q not in seen:
                seen.add(q)
                out.append(q)
        return ",".join(out)


    class ProjectCreate(BaseModel):
        ...
        @field_validator("country_qid")
        @classmethod
        def _resolve_country(cls, v: str) -> str:
            try:
                return _resolve_country_list(v)
            except ValueError as exc:
                raise ValueError(str(exc)) from exc


    class ProjectUpdate(BaseModel):
        ...
        @field_validator("country_qid")
        @classmethod
        def _resolve_country_optional(cls, v: str | None) -> str | None:
            if v is None:
                return v
            try:
                return _resolve_country_list(v)
            except ValueError as exc:
                raise ValueError(str(exc)) from exc
    ```
