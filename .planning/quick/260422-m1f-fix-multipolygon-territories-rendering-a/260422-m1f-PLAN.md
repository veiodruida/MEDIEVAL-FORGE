<objective>
Fix MultiPolygon territories (pravia, gijon, tui, coimbra, alicante, mallorca) rendering as white and being non-clickable on the canvas.

Purpose: The territories query `select` in `useCanvasArtifacts.ts` currently extracts only the FIRST outer ring per feature via `firstOuterRing()`. For MultiPolygon features, the remaining polygons are silently dropped — they appear as white background and cannot be clicked. Fix by expanding each MultiPolygon feature into one TerritoryRender entry per polygon, then adjust the two consumers (TerritoryLayer, InteractionLayer) to handle multiple renders sharing the same `id`.

Output: All polygons of a MultiPolygon territory fill with the correct color, are clickable, and receive the gold selection outline. No duplicate-key React warnings.
</objective>

With:
```ts
select: (raw: FC<CondadoFeature>): TerritoryRender[] => {
  if (!projection) return []
  const result: TerritoryRender[] = []
  for (const f of raw.features) {
    const rings: [number, number][][] =
      f.geometry.type === 'Polygon'
        ? [f.geometry.coordinates[0]]
        : f.geometry.coordinates.map((poly) => poly[0])
    for (const ring of rings) {
      result.push({
        id: f.properties.id,
        name: f.properties.name,
        points: geoRingToKonvaPoints(ring, projection),
        neighbors: f.properties.neighbors,
      })
    }
  }
  return result
},
```

In `InteractionLayer.tsx`, the current implementation uses `territories.find(...)` which returns only the FIRST matching polygon. For MultiPolygon territories, this means only one polygon of the selected territory gets the gold outline.

Replace the component body (lines 20-39) with filter-based logic that renders one `<Line>` per matching polygon:

```tsx
export function InteractionLayer({ territories }: Props) {
  const selectedTerritoryId = useUIStore((s) => s.selectedTerritoryId)
  const selectedPolygons = selectedTerritoryId
    ? territories.filter((t) => t.id === selectedTerritoryId)
    : []

  return (
    <Layer listening={false}>
      {selectedPolygons.map((t, i) => (
        <Line
          key={`${t.id}-${i}`}
          points={t.points}
          closed
          stroke="#f0c040"
          strokeWidth={3}
          listening={false}
        />
      ))}
    </Layer>
  )
}
```

Keep the existing JSDoc comment above the component (lines 9-19); the behavior it describes ("renders 0 children when selectedTerritoryId is null or unknown") still holds — update the wording "exactly one closed Line" to "one closed Line per polygon of the selected territory (MultiPolygon territories yield multiple lines)" so the comment stays accurate.
