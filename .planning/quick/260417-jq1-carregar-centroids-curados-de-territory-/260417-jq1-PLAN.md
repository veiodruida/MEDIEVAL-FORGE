<objective>
Formalise `inicio/territory_data_v3.py` as the authoritative source of Iberia's
curated territory hierarchy (KINGDOMS → DUCHIES → CONDADOS → BARONIES with
hand-curated lon/lat centroids), and lock the existing
`backend/medieval_forge/services/territory_iberia.json` to it via a deterministic
exporter + parity test.

**Key context finding (verified during planning):**
- `territory_iberia.json` already exists and already matches v3 exactly:
  4 kingdoms / 26 duchies / 92 condados / 257 baronies, first/last rows identical.
- The pipeline in `backend/medieval_forge/lib/map_generator.py` already uses the
  curated barony centroids as KD-tree anchors (see `setup_baronies` →
  `cKDTree(bpx[pi])` / `cKDTree(bpx[ei])` where `bpx` is built from
  `geo_to_pixel(blo, bla, cfg)` over the baronies in CONDADOS).
- The coordinate convention is `(lon, lat)` in both v3 and the pipeline — no
  conversion needed.
- Frontend obtains the template via `GET /api/projects/territory-template/iberia`
  (served from `territory_iberia.json`) and passes it as `territory_data` in the
  generate request body.

Therefore the implementation work requested in the quick task is already in place.
What is still missing — and what this plan delivers — is the **supply chain**
that keeps the JSON in sync with v3 and proves it today.

Purpose: eliminate risk of silent drift between `territory_data_v3.py` and
`territory_iberia.json`; make re-sync a one-command operation.

Output: a sync script, a regenerated (byte-identical) JSON, and a pytest that
fails if the two ever disagree.
</objective>

```python
def setup_baronies(condados, duchies, kingdoms, cfg):
    """Baronies become KD-tree anchors; each OSM municipality centroid is
    assigned to nearest barony via cKDTree.query. PT/ES split is enforced by
    separate KD-trees (tp for PT baronies, te for ES baronies)."""
    for ci, c in enumerate(condados):
        did = c[4]
        for bn, blo, bla in c[5]:
            px, py = geo_to_pixel(blo, bla, cfg)   # lon, lat → pixel
            bars.append({'name': bn, 'px': px, 'py': py, ...})
    ...
    tp = cKDTree(bpx[pi]) if pi else None   # PT-side baronies
    te = cKDTree(bpx[ei]) if ei else None   # ES-side baronies
    return bars, bpx, bc, bd, bk, pi, ei, tp, te
```
